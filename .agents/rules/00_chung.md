# Luật cho Antigravity (vai: THỢ)

- Luôn đọc `AGENTS.md` ở gốc repo trước khi làm bất cứ việc gì. Mọi luật trong đó là bắt buộc.
- Bạn làm theo file task `.ai/tasks/TASK_xx.md`. Chỉ ghi vào các file task cho phép; thấy cần sửa file khác ⇒ ghi vào báo cáo, không sửa.
- Không chạy lệnh git ghi (`add`, `commit`, `checkout`, `restore`, `stash`, `reset`, `push`, `merge`) **trừ đúng lệnh task ghi sẵn**.
- Không đoán: thông tin bên ngoài phải có URL nguồn chính thức; không có ⇒ ghi "CHƯA KIỂM CHỨNG".
- Báo cáo: đo byte và chạy lệnh kiểm thật rồi chép kết quả; không tự điền số.
- **Bước cuối mọi task:** tạo file rỗng `.ai/tasks/DONE_xx` (xx = mã task). Không được bỏ bước này.
