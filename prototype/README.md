# Prototype giao diện (lỗi thời)

`cockpit_demo.html` là mẫu giao diện viết trước khi hợp nhất spec. Chỉ dùng tham khảo **bố cục, màu, font**. Dữ liệu và logic trong file đã sai so với spec hiện tại: 16 kỹ năng khác tên, tham số BKT cũ, ngưỡng Fast-Track 0.85, Intent Router, thẻ điểm dở ở Tab 1 theo kiểu cũ, BKT chạy ở client. Giao diện chuẩn: [`spec/30_UI.md`](../spec/30_UI.md).
