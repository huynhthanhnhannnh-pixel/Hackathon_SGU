Quy định về sản phẩm code: Ngay sau khi công bố vòng thử thách, các đội thi cần thực hiện quy trình quản lý code như sau:
2.1. Nộp GitHub Repo trống:
Mỗi đội khởi tạo 01 GitHub Repository (Public) và nộp link cho BTC trước giờ làm bài.
Repository phải trống hoàn toàn. BTC sẽ kiểm tra repo trước khi vòng thi bắt đầu.
2.2 Đủ thành viên (Contributors):
Repo bắt buộc phải thêm tất cả thành viên trong đội vào danh sách Contributors/Collaborators. Các thành viên đều phải có đóng góp (commit) code.
2.3 Kiểm tra Commit Log: 
BTC sẽ kiểm tra lịch sử commit (Git log). Chỉ chấp nhận các commit trong thời gian thử thách.
Nghiêm cấm việc push hàng loạt (bulk commit) code đã chuẩn bị từ trước. 
Nếu phát hiện một trong những điều trên sẽ hủy bỏ tư cách thi của đội đó.
