## 2. Màn hình & bố cục

### 2.1. Màn hình trống (`result = null`)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [https://github.com/owner/repo                      ] [Quét repo]    │
│ ┌ Kéo thả file .zip vào đây ───────────────────────────────────────┐ │
│ └──────────────────────────────────────────────────────────────────┘ │
│ TIẾP TỤC HỌC                                                         │
│ shop-api · main @ 5be1c2a · 3/7 node (1 ✗) · 2 giờ trước [Học tiếp]  │
│ bai-tap.zip · zip 9f2c0d1 · 1/6 node  [Kéo thả lại bai-tap.zip]      │
└──────────────────────────────────────────────────────────────────────┘
```

- **UI-10** Ô link + "Quét repo" ⇒ `POST /api/ingest { repo_url }`. Client chỉ chặn ô rỗng; cú pháp do server kiểm (`ERR_INVALID_GITHUB_URL`).
- **UI-11** Vùng kéo thả chỉ nhận `.zip` ≤ `CONFIG.MAX_STREAM_BYTES`: sai đuôi ⇒ thông điệp `ERR_UPLOAD_INVALID`; quá cỡ ⇒ thông điệp `ERR_STREAM_QUOTA_EXCEEDED`; cả hai không gửi request. Hợp lệ ⇒ multipart, trường `archive`.
- **UI-12** "Tiếp tục học" = `GET /api/sessions`, sắp `last_active_at` giảm dần. Mỗi dòng: `repo_name`, `ref_label`, 7 ký tự đầu `snapshot_id` (`ARCHIVE_HASH` kèm chữ "zip"), `subdir` nếu khác rỗng, `completed_count / total_nodes` (+ `failed_count` ✗), thời gian tương đối. Nút chính:

| `can_resume` | `resume_blocker` | Nút |
| :-- | :-- | :-- |
| `true` | `null` | "Học tiếp" ⇒ `POST /api/ingest { session_id }` |
| `false` | `ZIP_SOURCE`, `snapshot.source = "ZIP"` | Vùng thả "Kéo thả lại {repo_key}" ⇒ upload như UI-11; server khớp khóa phiên ⇒ `resumed = true`. `session_id` trả về khác id cũ ⇒ toast "File khác bản cũ — đã mở phiên mới" |
| `false` | `ZIP_SOURCE`, `snapshot.source = "GITHUB"` | "Quét lại link" ⇒ điền ô link `https://github.com/{repo_key}` (+ `/tree/{ref_label}` nếu có); người học tự bấm Quét |
| `false` | `ENGINE_UPDATED` | Chỉ "Xem lịch sử" |

  Dòng nào cũng có "Lịch sử" ⇒ `/history?session={id}` (`GET /api/sessions/{id}/history`): bảng node · chế độ · câu · kỹ năng · lần · `core_accuracy` · đạt · `intent` · thời gian; bấm dòng ⇒ xem `student_answer`.
- **UI-13** Khách **chưa có phiên nào** thấy thêm "Đã lưu tiến độ bằng GitHub? Đăng nhập" ⇒ `supabase.auth.signInWithOAuth({ provider: "github" })`.
- **UI-14 Đang quét:** lớp phủ có vòng quét + đồng hồ đếm thời gian thật (không giả lập tiến độ từng tầng); khóa ô link và vùng thả. Xong ⇒ `active_tab = "OVERVIEW"`, `active_node_id = null`, ghi `sf.last_session`; `resumed = true` ⇒ toast "Đã mở lại {repo_name} — {completed}/{total} node".

## 5. Cột 2 — Code (Monaco, chỉ đọc)

- **UI-30 Model của node** = các bước nối tiếp. Mỗi bước: 1 dòng tiêu đề chú thích rồi tới `trace_steps[i].snippet`, ngăn nhau 1 dòng trống:
  ```
  // ── Bước 2 · BUSINESS_LOGIC · src/services/product.service.ts · listProducts [· origin_note]
  ```
  Ký hiệu chú thích: `#` với Python, `//` với ngôn ngữ còn lại. Cuối model: khối "Kiểu dữ liệu" = `dto_snippet` (bỏ nếu rỗng). Hàm thuần `buildSliceModel(node)` trả `{ text, lineMap, stepRanges }` (`src/components/code/slice-model.ts`).
- **UI-31 Số dòng gốc:** `lineNumbers: (n) => lineMap[n - 1] > 0 ? String(lineMap[n - 1]) : ""`; `lineMap` lấy từ `snippet_line_map`. Dòng tiêu đề, dòng trống, marker lược dòng (giá trị `0`) và khối kiểu dữ liệu không có số. Marker lược dòng tô mờ, nghiêng.
- **UI-32 Tô sáng:**

| Loại | Phạm vi | Kiểu |
| :-- | :-- | :-- |
